# Catholic Catechism App

A fast, responsive web application for searching and reading the Catholic Catechism.
Built with Vue 3, TypeScript, Vite, and Tailwind CSS.

## Features

- **Search by Number**: Easily jump to specific paragraphs (e.g. `451`).
- **Search by Section**: Look up sections (e.g. `1.1.2.3`).
- **Search Multiple Ranges**: Find multiple paragraphs or ranges at once (e.g. `522,711-716,722`).
- **Shareable Links**: URL hash updates automatically so you can share exact searches.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
